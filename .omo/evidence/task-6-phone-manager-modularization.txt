7. DEVIATIONS
-------------
- `phonemanager.ksp` NOT created (T7 owns KSP2+Dagger; a non-functional stub would
  not compile-verify meaningfully).
- Namespaces for Android modules are PATH-DERIVED by default in
  `configureAndroidCommon` (`:adapter` -> com.glassstorm.phonemanager.adapter, and
  later `:transport:grpc` -> ...transport.grpc). `:adapter` still declares its
  namespace explicitly, so behaviour is byte-identical today; the derivation exists
  so T9-T14 can add a module with ~10 lines. `:app` overrides it explicitly.
- `kotlin-test` was added to the catalog as an alias. Previously modules used
  `kotlin("test")`; the plugin reads the catalog instead, so the same artifact is
  resolved from the same Kotlin 2.1.0 pin (`org.jetbrains.kotlin:kotlin-test`).
